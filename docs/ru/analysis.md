## Запуск одного файла

Интерфейс работает с одним WAV, FLAC или MP3 за раз — это может быть полный микс, стем или
отдельный слой.

1. Перетащите файл в поле загрузки.
2. При желании добавьте заметку к версии, например `vocal stem после de-esser v2`.
3. Выберите `lofcz`, `FST` или оба.
4. Нажмите **Запустить анализ**.

Детекторы запускаются последовательно, каждый в своей Conda-среде. Каждый запуск пишется в
`data/runs/<run_id>/` и индексируется в `data/history.sqlite3`.

Анализ одного файла **не** создаёт baseline и не сравнивает его с предыдущими треками.
Сравнение всегда явное — см. [Сравнение A/B](comparison.md).

## Карточки score

  <img src="../images/ui-overview.png" width="100%"
       alt="Две карточки детекторов рядом над полосой вкладок: у каждой вероятность, статус и время работы с устройством, на котором считалось">
</p>

У каждого детектора своя карточка: вероятность, статус и время работы с устройством, на котором
считалось. Время важнее, чем кажется: это часть условий измерения, и запуск, который незаметно
свалился на CPU, — уже другое измерение, чем запуск на CUDA.

Читайте две карточки как два независимых мнения. Когда они расходятся, само расхождение и есть
результат — см. [Ограничения](limitations.md#когда-детекторы-расходятся).

## 3D-поверхность

Экономная поверхность `96 × 160` строится сразу после анализа. Отдельная кнопка перестраивает
её в `256 × 480` без повторного запуска детекторов: детекторы — самая дорогая часть, и повторный
прогон вдобавок создал бы вторую запись истории для того же аудио.

## Синхронизация с плеером

Все графики со шкалой времени связаны с плеером в обе стороны:

- клик по спектрограмме, RMS-динамике или спектральной A/B-разнице перематывает плеер на эту
  секунду;
- при воспроизведении по тем же графикам едет вертикальная полоска позиции.

Работает целиком в браузере ([`music_lab_ui/static/playback_sync.js`](../../music_lab_ui/static/playback_sync.js)),
без обращений к серверу — round-trip на каждый кадр был бы слишком медленным. График
подключается к синхронизации, только если помечен `layout.meta.time_axis` в `plots.py`; поэтому
на частотных графиках полоски нет — там она указывала бы на бессмысленную координату.

Полоска обновляется через `requestAnimationFrame` с ограничением ~25 кадров/с. В фоновой
вкладке браузер полностью останавливает `requestAnimationFrame`, поэтому есть запасной путь
через событие `timeupdate` (~4 раза в секунду).

## Информация о файле

Технические данные фиксируют имя файла, формат, длительность и SHA-256 входа. Именно хэш делает
измерение прослеживаемым: если нельзя доказать, какой файл дал число, число невоспроизводимо.
