# Данные детекторов

[← Документация](README.md) · [English](../detector-data.md)

**Вопрос, на который отвечает вкладка:** что модель на самом деле посчитала, прежде чем это
свернули в одно число?

Телеметрия хранится отдельно от итогового score, по каждому запуску:

```text
data/runs/<run_id>/telemetry/<detector>/
├── telemetry.json   # конфигурация, scalar values, warnings, shapes, checksum
└── arrays.npz       # полные сырые массивы, доступны для скачивания из интерфейса
```

## lofcz

| Сигнал | Что это |
| --- | --- |
| Средний спектр 1–8 кГц | Диапазон, в котором работает модель |
| Lower hull | Нижняя огибающая, подогнанная к этому спектру |
| Residue | Расстояние между спектром и огибающей |
| Fakeprint | Точный вектор из 3585 значений, который подаётся в ONNX |

Эти данные **усреднены по времени**. lofcz не сообщает, в какой секунде расположен
«AI-фрагмент» — именно поэтому [карта по времени](timeline.md) существует как отдельный проход
скользящим окном.

## FST

| Сигнал | Что это |
| --- | --- |
| Beats / downbeats | Найденная ритмическая сетка |
| Валидные сегменты | 10-секундные beat-aligned сегменты, которые удалось использовать |
| Выходы классов Stage-1 | Оба сырых выхода |
| MERT embeddings | Эмбеддинг-представление |
| Self-similarity matrix | Структурная повторяемость внутри трека |
| Fusion-gate timeline | Как два этапа комбинировались во времени |

Индексы Stage-1 намеренно **не** переименованы из `class 0 / class 1` в `Real / Fake`. Upstream
не публикует однозначного соответствия, и выдумать его здесь означало бы превратить сырой выход
модели в ложное утверждение.

## Как правильно читать графики

Эти графики описывают **сигналы и вклад модели**. Они не размечают области «здесь AI». Пик
fusion gate означает, что модель иначе взвесила этот сегмент, — а это не то же самое, что «этот
участок сгенерирован».

## Граничные значения

`1.1%` и `98.9%` — нижняя и верхняя границы выходной шкалы upstream FST (`0.011 … 0.989`), а не
калиброванная гарантия. Увидеть `1.1%` означает «на нижней границе шкалы или ниже», а не
«точно живое».

## Когда FST возвращает «не применимо»

FST может отказаться от вокала и других стемов без устойчивых beats и downbeats. Это ожидаемое
ограничение upstream, а не сбой UI: адаптер завершается с явным сообщением
`FST preprocessing found no beat-aligned segments`, вместо того чтобы записать выдуманный
`Real / NaN`.

## Старые запуски

Запуски, сделанные до появления телеметрии, остаются читаемыми, но телеметрии у них нет. Чтобы
её получить, проанализируйте файл заново — это создаст новую версию, а не задним числом
дополнит старую, и каждая запись истории остаётся честной записью того, что реально измерялось
в тот момент.
